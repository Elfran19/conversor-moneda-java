# Conversor de Monedas

Proyecto desarrollado para el Challenge Oracle Next Education + Alura Latam.

## Descripción

Aplicación en Java que consume una API de tasas de cambio para convertir monedas.

## Tecnologías

- Java
- API ExchangeRate
- Gson
- Git
- GitHub

## Funcionalidades

- Conversión USD → ARS
- Conversión ARS → USD
- Conversión USD → BRL
- Conversión BRL → USD
- Conversión USD → COP
- Conversión COP → USD

Proyecto desarrollado para el programa Oracle Next Education.
